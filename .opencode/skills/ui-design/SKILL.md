Avoid generic AI-template aesthetics.

Use:
- strong typography
- deliberate spacing
- clear visual hierarchy
- premium composition
- meaningful animation
- responsive layouts

Dashboard:
- information-dense
- easy to scan
- efficient
- professional

Landing page:
- memorable
- polished
- recruiter-friendly
- visually distinctive

Use animation purposefully.

Support reduced-motion preferences.

Do not allow visual effects to reduce usability or accessibility.

Prefer GPU-friendly animation techniques.
