---
name: frontend
description: React and TypeScript engineering standards for the Job Hunter application.
---

Use:
- React
- TypeScript
- Vite
- Tailwind CSS

Prefer feature-based organization.

Use explicit types.

Avoid unnecessary global state.

Every important screen should handle:
- loading
- empty
- error
- success

Use accessible semantic HTML.

Keep components reasonably sized.

Optimize for responsive desktop and mobile layouts.

Avoid generic SaaS boilerplate visuals.
